Поиск и ручной порядок: отдельные продуктовые срезы

Эта папка содержит материал для изучения кода и подготовки отдельных предложений
в CoMaps. Файлы не являются готовыми описаниями PR или подтверждением принятия
изменений сопровождающими. Существующие правила человеческого авторства,
раскрытия AI-участия и DCO остаются в силе; публикация не выполняется.

Что было в CoMaps до наших изменений

Внутри папки уже есть поиск точек и автоматические сортировки. Доступность
отдельных сортировок зависит от содержимого и наличия позиции пользователя.
Ядро также уже поддерживает режимы порядка папок. На первом уровне iOS
не было интерфейса общего поиска и управления этим порядком.

Что добавляют срезы

search.patch: поиск точек и треков по всем папкам, группировка результатов
по папке, а также поиск треков внутри выбранной папки. Точки и треки имеют
разные типизированные ID; отменённые и устаревшие ответы не заменяют текущие.
В UI поиск идёт по именам и префиксу, включая оригинальное/пользовательское
имя точки и существующие типовые псевдонимы. Поиск по описаниям и названиям
самих папок в этом предложении не заявлен.

folder-order.patch: управление существующими режимами папок на первом уровне
iOS, ручное перетаскивание и локальное сохранение порядка, в том числе пустых
папок. Стабильная идентичность папки используется при действиях меню.
Это не передача порядка между устройствами: iCloud KVS здесь отсутствует.

item-order.patch: отдельный ручной порядок точек и треков внутри папки,
сохранение порядка и режима в KML, проверка состава ID перед перестановкой,
корректное добавление, перенос, удаление и отмена удаления. Прежние
автоматические сортировки сохраняются. Это не смешанный список точек и треков.

Каждый patch применяется ОТДЕЛЬНО к чистой ревизии из manifest.json. Это три
самостоятельных кандидата, а не последовательный series.txt: они затрагивают
общие файлы. После принятия одного изменения другие нужно перебазировать.
Полная рабочая Lab по-прежнему собирается из patches/series.txt; эти срезы
не заменяют её проверенную историю.

Проверки

Manifest фиксирует ревизию, SHA-256 каждого patch, точные исходники и планы
тестов. Отдельный режим существующего ios.yml с saved_items_proposals=true
собирает каждый срез в чистой CoMaps, выполняет native-тесты, прежнюю
автоматическую сортировку, XCTest без пропусков и unsigned Release archive.
Текущий результат нужно смотреть на точном SHA запуска CI; применение patch
и синтаксическая проверка сами по себе не доказывают успешную сборку.

Пользователь подтвердил реальное перетаскивание в установленной Mac Lab как
на первом уровне, так и внутри папки, и сохранение после перезапуска. В той
сборке вход внутри папки был через Sort… → Edit. Новое изменение объединяет
вход: верхняя Edit включает перестановку на обоих уровнях, Done завершает её;
внутри папки сохраняются кнопки удаления. Удаление завершает текущую сессию
перестановки, чтобы не использовать устаревшие ID. Edit недоступна при поиске.
Автоматическая AX-команда Move up ранее меняла только вид строк и не служит
доказательством сохранения. Новый вход должен пройти отдельный CI и проверку
обновлённой сборки; пользователь подтвердил прежний рабочий алгоритм.

В срезы не входят синхронизация iCloud, исправления её файловых гонок,
Mac Catalyst-адаптация, внешний вид окна, Lab-идентичности и упаковка/подпись.
